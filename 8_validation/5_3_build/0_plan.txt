Core principle

The comparison should evaluate the entire DMR-selection-to-prediction pipeline:

outer training families→DMR discovery→feature construction→model tuning→prediction of untouched test families

For every outer split, each method must use only the DMRs selected from that split’s 80% training families. The corresponding 20% test families must not influence DMR selection, feature construction, imputation, PCA, tuning, or threshold choice.

The four methods should use the same 100 family splits and the same test subjects, making every comparison paired.

3. Feature construction
Recommended primary feature representation

Use PC1 and PC2 from each DMR, followed by LASSO.

This maintains continuity with your pilot comparison, where the selected comparison model was:

allDMR_PC12_LASSO

PC1 and PC2 are also more appropriate than a regional mean when a DMR contains positional changes that could cancel out when averaged.

Critical correction to the pilot code

Your pilot creates DMR PCs before separating training and test samples. It imputes each CpG using all subjects and runs prcomp() on the complete sample matrix.

That introduces test-set information into the PCA representation.

For every DMR and split, instead:

Extract the DMR CpGs for training and test subjects.
Apply the arcsine-square-root transformation.
Estimate each CpG’s missing-value median from training subjects only.
Apply those training medians to both training and test subjects.
Remove CpGs with zero training variance.
Estimate PCA center, scale, and rotation from training subjects only.
Generate training PC scores.
Project test subjects using the training PCA rotation.

Conceptually:

pca_train <- prcomp(
  training_matrix,
  center = TRUE,
  scale. = TRUE
)

PC_train <- pca_train$x[, 1:2]

PC_test <- predict(
  pca_train,
  newdata = test_matrix
)[, 1:2]

Never rerun prcomp() separately on the test set.

DMR PC1/PC2 + age + sex + smoking + BMI

Your pilot already used these four covariates.

I recommend keeping clinical covariates unpenalized:

penalty.factor = c(

This means:

DMR methylation features are LASSO-selected;
age, sex, smoking, and BMI remain in every model;

Inner cross-validation

Your pilot uses:

  ...,
  nfolds = 10,
  type.measure = "auc"

without supplying family-grouped foldid.

Therefore, related individuals could appear in different inner folds.

For the new analysis, use five inner folds defined at the family level:

cv.glmnet(

)

All members of the same FID must share the same inner fold.

Use the same inner-fold assignment for all four DMR methods within a given outer split.

Do not discard that split. Fit the covariate-only model:

Technical failures should be rerun rather than treated as no-DMR results.
